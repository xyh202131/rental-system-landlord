# 租房系统-房东端

面向房东的房屋采集与三维预览工具。当前方案聚焦简单登录、用户中心证件核验 Mock（身份证两面与房产证）、实时拍摄、素材暂存、Agent 指导，以及重建后的内部预览与质检。

**当前已实现可运行的本地最小 MVP，使用浅色界面。支持真实登录、实时相机采集和持久草稿；证件核验为流程 Mock，外部 Agent 与重建服务可选配置。**

账号准备：登录 → 用户中心 → 身份证人像面、国徽面与房产证 Mock 核验 → 标注通过。未通过时禁止新建和继续采集，服务端同时拦截主线写入。

采集主线：现场采集 → 拍后复查 → 空间成果。证件核验不占用主线步骤；通过后返回“我的采集”创建房屋/房间记录，随时暂存或补拍。

房屋采集没有相册或文件导入入口。已完成素材保存在本机 Node 服务的 SQLite 与素材目录，刷新、退出登录或重启服务后均可恢复。未配置视觉模型时，只做真实的本地亮度/数量检查和基础建议；不冒充视觉 Agent。现已接入本地家具试摆；无完整管理后台、独立租客门户或公开发布功能。

## 启动

需要 Node.js 24+。在本项目目录执行：

```powershell
npm ci
npm run build
npm start
```

打开 [本机体验入口](http://localhost:4317)。首次启动生成 `landlord` 账号和随机密码，查看 [.data/local-login.txt](.data/local-login.txt)。该文件、数据库、素材和 `.env` 均不纳入 Git。

默认监听 `127.0.0.1`，供当前电脑上的 Edge/Chrome 使用。手机拍摄需要另行配置可信 HTTPS 访问；本轮没有部署，也未承诺局域网 HTTP 可以开启手机相机。

## 本地家具试摆

左侧“家具试摆”可选择已有房间；也可从“重建样例”或成功重建预览点击“送入本地试摆”。当前本地接入复用现有登录、模型接口与三维移动控制，不需要额外启动租客服务。

支持内置样例、当前账号的导入案例和成功重建成果。可添加多件家具、点选参考地面落位、移动、旋转、调整比例、移除并保存布局；布局按账号、房间和模型版本隔离。刷新或重启后可恢复；冲突或保存失败会提示，不会静默覆盖。房间与家具比例未标定，界面标注“比例示意”。

首轮家具使用材料包内已有 GLB，保存在被 Git 忽略的 `.data/furniture/`，不创建图生 3D 任务。模型准备、存储边界与验证命令见 [本地家具试摆说明](docs/本地家具试摆.md)。自动抓拍、付费家具生成与真机 AR 留待后续接入。
